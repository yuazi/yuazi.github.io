Qubits decohere and gates are imperfect, so a long computation needs a way to detect and undo errors without looking at the data. Classical codes copy bits and take a majority vote. Quantum states cannot be copied, and measuring them destroys them, so quantum error correction has to get the same protection from entanglement and indirect measurement. It is the reason people expect fault-tolerant machines to exist at all, and the reason they will need thousands of physical qubits per useful logical qubit.

## Mental Model

- Spread one logical qubit over many physical qubits, then measure parity checks (syndromes) that reveal where an error happened without revealing the encoded amplitudes.
- No-cloning forbids copying $\alpha\lvert 0\rangle + \beta\lvert 1\rangle$, but it allows the entangled encoding $\alpha\lvert 000\rangle + \beta\lvert 111\rangle$.
- Any single-qubit error is a combination of $I$, $X$, $Z$ and $XZ$, so correcting bit flips and phase flips corrects everything. Continuous errors get projected onto these discrete ones by the syndrome measurement.
- Encoding only helps below a threshold: if physical error rates are too high, adding qubits adds more errors than it removes.

## 1. Why Classical Tricks Fail

The no-cloning theorem says no unitary maps $\lvert\psi\rangle\lvert 0\rangle$ to $\lvert\psi\rangle\lvert\psi\rangle$ for every $\lvert\psi\rangle$. So the repetition code "write the bit three times" cannot be applied to an unknown state. Reading out the qubits to compare them is no escape either, since a measurement collapses the superposition ([[notes/quantum/measurement-and-the-born-rule|Measurement and the Born Rule]]). Errors are also continuous, a small unwanted rotation rather than a clean flip, and there are two kinds to track: bit flips ($X$) and phase flips ($Z$).

## 2. The Three-Qubit Bit-Flip Code

Encode with two CNOTs from the data qubit onto two fresh qubits:

$$
\alpha\lvert 0\rangle + \beta\lvert 1\rangle \;\mapsto\; \alpha\lvert 000\rangle + \beta\lvert 111\rangle.
$$

This is not three copies of the state. It is a GHZ-like entangled state, so no-cloning is respected. Now measure the two parities $Z_1Z_2$ and $Z_2Z_3$, each with an ancilla. Each parity operator has eigenvalue $+1$ on both $\lvert 000\rangle$ and $\lvert 111\rangle$, so the measurement learns nothing about $\alpha$ and $\beta$. After an $X$ error on one qubit the two eigenvalues change as follows. I checked this with a Qiskit statevector for $\alpha = 0.6$, $\beta = 0.8$.

| Error | $Z_1Z_2$ | $Z_2Z_3$ | Fix         |
| ----- | -------- | -------- | ----------- |
| none  | +1       | +1       | none        |
| $X_1$ | -1       | +1       | apply $X_1$ |
| $X_2$ | -1       | -1       | apply $X_2$ |
| $X_3$ | +1       | -1       | apply $X_3$ |

Applying the fix returns exactly $0.6\lvert 000\rangle + 0.8\lvert 111\rangle$. If each qubit flips independently with probability $p$, the code fails when two or more flip, so the logical error rate is $3p^2 - 2p^3$. At $p = 0.01$ that is $2.98 \times 10^{-4}$, about 34 times better. At $p = 0.5$ it equals $p$, and above that it is worse, a small-scale version of the threshold idea.

> [!warning] Common mistake
> This code does nothing against $Z$ errors. A phase flip on any one qubit gives $\alpha\lvert 000\rangle - \beta\lvert 111\rangle$, which all $Z$-parity checks accept.

## 3. The Phase-Flip Code

Apply Hadamards to all three qubits of the bit-flip code. The logical states become $\lvert +++\rangle$ and $\lvert ---\rangle$, and a $Z$ error acts as $\lvert +\rangle \leftrightarrow \lvert -\rangle$, which is a bit flip in this basis. The syndromes are $X_1X_2$ and $X_2X_3$, and the table above holds with $Z_i$ in place of $X_i$ (the same Qiskit check confirms it). The code now fixes one $Z$ error and none of the $X$ errors.

## 4. Shor's Nine-Qubit Code

Concatenate the two. Encode the qubit in the phase-flip code, then encode each of its three qubits in a bit-flip code. That gives nine physical qubits arranged as three blocks of three. Bit flips are caught inside each block, phase flips are caught by comparing blocks. A $Y$ error is $XZ$, so both layers act, and the code corrects any single-qubit error. This was the first proof that quantum error correction is possible (Shor, 1995). Better codes exist: the smallest that corrects an arbitrary single-qubit error uses five qubits.

## 5. Stabilizers in One Section

The checks above are an instance of a general pattern. A stabilizer code is defined by a group of commuting Pauli operators $S_i$ (the stabilizers). The code space is the set of states with $S_i\lvert\psi\rangle = +\lvert\psi\rangle$ for all $i$. For the bit-flip code the group is generated by $Z_1Z_2$ and $Z_2Z_3$.

An error $E$ that anticommutes with some $S_i$ flips that check's measured value, so the list of $\pm 1$ outcomes is the syndrome. The decoder maps a syndrome to the most likely error and applies the inverse. An error that commutes with every stabilizer but is not itself in the group (a logical operator, like $XXX$ in the bit-flip code) is invisible and corrupts the data. The code distance $d$ is the weight of the smallest such operator, and the code corrects up to $\lfloor (d-1)/2 \rfloor$ errors. Because stabilizer measurements are just Pauli measurements, hardware only needs a small gate set to run them.

## 6. The Surface Code

The surface code puts data qubits on a 2D grid with alternating $X$-type and $Z$-type stabilizers on the faces, each touching four neighbors. That fits the nearest-neighbor connectivity of superconducting chips ([[notes/quantum/quantum-hardware|Qubit Hardware Platforms]]). A distance-$d$ patch uses $d^2$ data qubits and $d^2 - 1$ measurement qubits, so $2d^2 - 1$ in total: 17 for $d = 3$, 49 for $d = 5$, 241 for $d = 11$.

Below a threshold error rate $p_{th}$, which is roughly 1% for the circuit-level noise models usually quoted (an approximate figure that depends on the noise model and decoder), the logical error rate falls as a rough scaling

$$
p_L \;\sim\; \left(\frac{p}{p_{th}}\right)^{(d+1)/2}.
$$

With $p/p_{th} = 0.1$ this gives $10^{-2}$ at $d = 3$, $10^{-3}$ at $d = 5$, and $10^{-6}$ at $d = 11$. Real prefactors differ, so treat these as orders of magnitude. Each increase of $d$ by two multiplies the logical error rate by a constant factor below one, so the qubit overhead grows only polynomially with the target accuracy.

## 7. Overhead

Fault-tolerant algorithms need logical qubits plus extra space for gates and for distilling the non-Clifford gates (T gates) that stabilizer codes cannot perform directly. With a surface code at $d \approx 11$ to 25 the cost is hundreds to over a thousand physical qubits per logical qubit. Factoring a large RSA number ([[notes/quantum/shors-algorithm|Shor's Algorithm]]) therefore points at millions of physical qubits, and current devices have hundreds to low thousands. Other codes with higher encoding rates are active research, but the connectivity they need is harder to build.

## 8. Mitigation vs Correction

Error mitigation runs the noisy circuit anyway and removes the bias in post-processing, for example by extrapolating to zero noise or by cancelling known noise channels. It needs no extra qubits, but its sampling cost grows exponentially with circuit size, and it gives expectation values, not a protected quantum state. Error correction keeps the state itself intact and scales polynomially, but only works below threshold and costs many qubits. Today's experiments use mitigation.
